# 💻 TechConnect 2026

### Abasyn University Peshawar Tech Event Website

**TechConnect 2026** is a modern event website designed for a technology event at **Abasyn University Peshawar**. The platform provides students and visitors with information about the event, activities, schedule, speakers, and registration.

The project focuses on creating a modern, responsive, and engaging frontend experience for a university technology event.

---

## 📌 Project Overview

TechConnect 2026 is designed to provide a central online platform for the event.

Visitors can explore:

* Event information
* Event schedule
* Speakers and guests
* Event activities
* Registration information
* Venue and event details
* Important announcements

The website is designed with a modern technology-focused visual style.

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/Muhammad-Osama-84/TechConnect-2026.git
```

Open the project folder:

```bash
cd TechConnect-2026
```

Then open:

```text
index.html
```

in your browser.

You can also open the project in **Visual Studio Code** and use the **Live Server** extension.
